# ⚽ RB Futebol Clube - ScoutApp

Aplicativo Web (PWA) desenvolvido para gerenciar as estatísticas e scout dos jogos do RB Futebol Clube. O sistema funciona offline, salva dados no navegador e permite exportação de relatórios.

## 🚀 Funcionalidades

- **Scout em Tempo Real:** Registro de gols, assistências, finalizações, desarmes e cartões.
- **Autenticação Simples:** Proteção de acesso inicial via senha (persistente no dispositivo).
- **Rankings Automáticos:** Tabelas de Artilharia, Assistências, Craque da Rodada e Geral.
- **Gestão de Presença:** Importação de lista do WhatsApp e controle de mensalistas/avulsos.
- **Backup Local:** Sistema de exportação/importação de dados via código base64.
- **Histórico:** Log completo de partidas passadas.

## 🛠️ Tecnologias

- HTML5 / CSS3 / JavaScript (Vanilla)
- LocalStorage (Banco de dados no navegador)
- PWA (Pode ser instalado no celular)

## ⚙️ Configuração

Para utilizar este projeto para sua própria equipe:

1. Clone o repositório.
2. Abra o arquivo `index.html`.
3. Procure pela variável `const SENHA_EQUIPE` e altere a senha padrão.
4. Hospede gratuitamente no Vercel ou GitHub Pages.
